# Traffic-Statistik brunnen-3d

Täglich gesichert durch `.github/workflows/traffic-stats.yml` (auf `main`).

- `views.csv` – Seitenaufrufe pro Tag
- `clones.csv` – Git-Klone pro Tag
- `referrers.csv` – Herkunft der Besucher (14-Tage-Summe, täglicher Schnappschuss)
- `paths.csv` – meistbesuchte Seiten (14-Tage-Summe, täglicher Schnappschuss)
